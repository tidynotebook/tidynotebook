# Workspaces

This page is for the person who writes notes. It shows how to keep two sets of
notes apart, for example personal notes and work notes, and how to switch
between them.

A workspace is a separate set of notes. When you read one workspace, notes of
the other workspaces never appear.

## Switch to another workspace

1. Select the name of the open workspace at the top of the sidebar. A menu
   lists every workspace of your account.
2. Select the workspace that you want.

You can also press **Ctrl + P**, or **Cmd + P** on a Mac, to open the command
palette. Then type the name of the workspace.

Each device remembers the workspace that you opened last. A second device can
stay on a different workspace.

## Make a workspace

1. Select the name of the open workspace at the top of the sidebar.
2. Select **New workspace**.
3. Enter a name in **Workspace name**.
4. Select **Make workspace**.

The new workspace opens, and it is empty. Select **New note** to fill it.

## Rename a workspace

1. Select the name of the open workspace at the top of the sidebar.
2. Select **Rename workspace**.
3. Enter the new name in **Workspace name**.
4. Select **Rename workspace** again to save it.

The notes do not change.

Your account starts with one workspace, named Personal. Every note that you
make before you make another workspace is in it. You can rename it.

## Delete a workspace

Every note, every version and every published link of the workspace goes. Trash
does not hold them, and you cannot get them back. Export the notes first if you
want to keep them. See [Export](export.md).

1. Open the workspace that you want to delete.
2. Select the name of the workspace at the top of the sidebar.
3. Select **Delete permanently**.
4. Type the name of the workspace to confirm.
5. Select **Delete permanently** again.

Your account always keeps one workspace. When you have only one workspace, the
menu does not show **Delete permanently**.

## What a workspace keeps apart

A workspace has its own notes, folders, Trash, published links and history.
The note list, the search results, the command palette and the list **Links to
this note** each show only the workspace that you have open.

A folder does not do this. A folder groups notes inside one workspace, and
every note is still in the list. Use a folder to group. Use a workspace to
separate.

## What a workspace does not do

- A note cannot link to a note in another workspace. A link between notes
  works inside one workspace.
- Search reads the workspace that you have open. To find a note in another
  workspace, open that workspace first.
- A note cannot move between workspaces. Export it and write it again in the
  other workspace.
