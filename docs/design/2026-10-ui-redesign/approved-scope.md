# Approved implementation scope

Status: active

The owner approved the wireframes in commit 2b7a9ebf ("baseline") and asked
that every fix also apply on desktop. The later commits c3a81551 and 4f70eab1
("polish") can guide visual styling only. Behaviour that the polish adds is
not approved unless the table below includes it.

Read the baseline with
`git show 2b7a9ebf:docs/design/wireframes/2026-10-ui-redesign/index.html`.
Screen IDs in the baseline and in the polish pages are different. The table
names both.

## Optional proposals, not in scope

These are separate proposals. They do not block the approved fixes:

- Tips that rotate on each visit with no Next button.
- An account menu on the avatar.
- Spelling as a switch in the Settings list.
- Search with no results offering a new note.
- A fixed `6 second` Undo message.
- Upload time and waiting count in the save details.
- Changed sign-out button emphasis or choices.
