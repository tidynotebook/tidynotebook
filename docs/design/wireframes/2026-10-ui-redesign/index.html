tidy notebook: redesign of the UI shipped in v0.22.0

Mobile first. One filled button per screen. Real buttons with a visible edge. No "workspace root". Tips are one short line. Settings is a list that opens one page per topic. All data safety behavior stays the same. Copy in the frames is the proposed copy.

A1screen ID used in the flow mapYellow tag: prototype markerFrames: 360 px phone, 1180 px desktop

A. All notes and navigation

Fixes: "Create in" line removed. "From template" becomes a real outlined button next to the one filled button. Tips shrink to one line with Next and Close. Today's note moves to navigation, where it always is.

B. New note from a template

Two steps in a bottom sheet: pick, then preview and create. The save place is one row, "Folder", with a Change button. "No folder" replaces "workspace root".

C. Settings

Phone: one list of rows. Each row opens its own page with a Back button. Each page has a one line description at most. No duplicate titles. Desktop: list on the left, page on the right (D3).

D. Editor, save status and recovery

One status pill in the bar. Undo and Redo are arrow icon buttons with no visible text, first in the format bar. Draft recovery is a choice between two tabs, not two long stacked blocks.

D6Undo and Redo icon buttons (prototype spec)

Curved arrow icons only. No visible "Undo" or "Redo" text in the editor. Light row, then dark row.
