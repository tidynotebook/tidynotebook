Email review: tidy notebook

Every message of the core and the one cloud notice, in the proposed design. Each message has an HTML part and a plain text part with the same meaning. The HTML part loads no remote file, no picture, no font and no tracking pixel. Every link is a link of the product. The token in a sample link is a placeholder. The dark frames show a client that reads the dark media query, such as Apple Mail. The inverted frame is a rough approximation of a client that inverts colours by itself. Real clients must be checked with an approved test inbox before release.
